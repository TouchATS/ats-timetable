เตรียมข้อมูลเผยแพร่สำหรับผู้ดูแล

เปิดไฟล์นี้บนเครื่อง เลือกไฟล์สำรอง JSON จากโปรแกรมตารางสอนเดิม แล้วเลือกหลักสูตรที่จะให้ครูดู

ข้อมูลที่ส่งออกจะเปิดเผยต่อสาธารณะ กรุณาตรวจตารางก่อนอัปโหลด ไม่รวมบัญชีผู้ใช้หรือข้อมูลประวัติบุคคล

นำไฟล์ที่ได้ไปแทน docs/schedule.json ใน GitHub แล้ว Commit changes การเปลี่ยนข้อมูลบนเว็บทำได้เฉพาะผู้มีสิทธิ์เขียน Repository
