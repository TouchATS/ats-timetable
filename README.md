# ATS Timetable เวอร์ชั่น 2 — GitHub Pages + Firebase

เว็บใช้หน้าตาและโปรแกรมจาก ตารางสอน/เวอร์ชั่น 2/ats-main เชื่อม Firebase ats-timetable ใหม่
ผู้ดูข้อมูลเปิดดู/พิมพ์ได้ ผู้ดูแลเข้าสู่ระบบด้วย Username และรหัสผ่าน
admin1 ใช้รหัสผ่านบัญชี Firebase ที่เจ้าของระบบสร้างใหม่ ไม่ใช่รหัสผ่านจากโปรแกรมเดิม
Super Admin สร้างบัญชีใหม่ด้วย Username ในหน้าจัดการแอดมิน โปรแกรมสร้างรหัสบัญชีภายใน Firebase ให้อัตโนมัติ ไม่ต้องใช้อีเมลส่วนตัว
บัญชีเดิม admin2/admin3/admin4 ต้องสร้างใหม่ เพราะไม่สามารถย้ายรหัสผ่าน SHA-256 เดิมเข้า Firebase Authentication ได้
Admin จัดการหลักสูตร ตารางสอน และข้อมูลครู/วิชาได้ Super Admin จัดการผู้ใช้ สิทธิ์ และชื่อโรงเรียนได้ด้วย
บันทึกส่วนกลางด้วย Firebase REST พร้อมตรวจ ETag ป้องกันบันทึกทับข้อมูลที่ผู้อื่นเพิ่งแก้
รายการดูสาธารณะอัปเดตทุก 30 วินาที ข้อมูลบทบาทไม่เปิดสาธารณะ
การลบผู้ใช้ในโปรแกรมคือถอนสิทธิ์ฐานข้อมูล บัญชี Authentication ยังอยู่เพื่อให้เจ้าของระบบลบ/กู้คืนผ่าน Console
รีเซตรหัสผ่านบัญชีอื่น และนำเข้าไฟล์สำรองให้ดำเนินการผ่าน Firebase Console โดยเจ้าของระบบ ฟังก์ชั่นบันทึก Log เดิมยังไม่ได้ย้ายมา Firebase
ห้ามใส่รหัสผ่าน, refresh token, service account หรือไฟล์ users เก่าใน Repository

เข้าสู่ระบบคงอยู่เมื่อรีเฟรชหน้าในแท็บเดิม และออกจากระบบเมื่อไม่มีการใช้งาน 30 นาที การโหลดข้อมูลอัตโนมัติไม่ต่อเวลาใช้งาน การกลับมาจากแท็บพักจะตรวจหมดเวลาทันที

ก่อนออกจากระบบอัตโนมัติจะบันทึกฟอร์มหลักสูตร ตารางสอน วันหยุด ครู และวิชาที่แก้ไขอยู่และผ่านการตรวจสอบลง Firebase ถ้าข้อมูลไม่ครบหรือบันทึกไม่ได้ จะเก็บฉบับร่างใน sessionStorage เฉพาะบัญชีและแท็บเดิม ให้ Login บัญชีเดิมแล้วกดเปิดทำต่อ ห้ามปิดแท็บหากยังต้องการฉบับร่าง ไม่เก็บฟอร์มบัญชีผู้ใช้หรือรหัสผ่านอัตโนมัติ

คัดลอกหลักสูตรจะได้ฉบับร่างพร้อมรายการทั้งหมดในธุรกรรมเดียว (ไม่เปิดสาธารณะในหน้าดูตาราง) ฉบับร่างแก้รายการที่มีเวลาซ้ำได้และแสดงคำเตือนสีแดง เปลี่ยนวันเปิดพร้อมเลือกเลื่อนทั้งตารางเพื่อเลื่อนวันสอน วันหยุด และวันปิด ปุ่มเปิดใช้งานตรวจวิชาซ้ำกับหลักสูตรใช้งานและภายในหลักสูตรจากข้อมูลล่าสุดก่อนเผยแพร่ ฉบับร่างอื่นไม่ขวางหลักสูตรที่ใช้งานอยู่ ข้อมูลฉบับร่างยังอยู่ในฐานข้อมูลตารางที่อ่านผ่าน API สาธารณะได้ จึงไม่ใช้เก็บข้อมูลลับ
