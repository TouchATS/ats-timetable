# ตารางสอน เวอร์ชั่น 1 บน GitHub Pages

ใช้หน้าตา การเลือกหลักสูตร ตารางรายสัปดาห์ และหน้าพิมพ์จาก timetable_military.html ของเวอร์ชั่น 1
ข้อมูล 2 หลักสูตร 142 รายการ มาจาก ตารางสอน/เวอร์ชั่น 1/ats-main/data.json
ครูเปิดดูโดยไม่ต้องเข้าสู่ระบบ ผู้ดูแลแก้ไขในโปรแกรมต้นฉบับแล้วอัปเดต docs/data.json บน GitHub
ข้อมูลที่เผยแพร่รวมหลักสูตรตัวอย่างที่เดิมซ่อนไว้ตามคำสั่งให้นำหลักสูตรทั้งหมดมาแทน
ห้ามอัปโหลด users, รหัสผ่าน, token หรือไฟล์สำรองเต็มจากโปรแกรมเดิม
GitHub Pages ตั้งค่า main /docs ไว้แล้ว ระบบออนไลน์นี้เปิดโหมดดูข้อมูล ไม่มีการเชื่อม Firebase เดิมและไม่มีการบันทึกข้อมูลกลางจากเบราว์เซอร์
