# ตารางสอนสำหรับครู — GitHub Pages

ครูเลือกหลักสูตร ค้นหาวิชา/ผู้สอน/สถานที่ กรองช่วงวันที่ และพิมพ์หรือบันทึก PDF ได้ ไม่มีระบบ Login หรือฐานข้อมูลออนไลน์

## เริ่มใช้
1. สร้าง Repository ชื่อ ats-timetable บน GitHub เลือก Public หากใช้ GitHub Free
2. อัปโหลดโฟลเดอร์ docs จากชุดนี้ ให้เห็น docs/index.html และไฟล์อื่นข้างใน (อย่าอัปโหลด ZIP โดยไม่แตก)
3. Settings → Pages → Source: Deploy from a branch → Branch: main → Folder: /docs → Save
4. รอ GitHub แสดงลิงก์เว็บไซต์ แล้วส่งลิงก์ให้ครู

## ผู้ดูแลอัปเดตตาราง
1. จัดตารางในโปรแกรมเดิมและส่งออกไฟล์สำรอง JSON ด้วยบัญชีผู้ดูแลโปรแกรมสูงสุด
2. เปิด tools/publisher.html บนเครื่อง ไม่ต้องนำเครื่องมือนี้ขึ้นเว็บ
3. เลือกไฟล์สำรอง เลือกหลักสูตร และเลือกว่าจะเผยแพร่ชื่อผู้สอนหรือไม่ (ค่าเริ่มต้นไม่เผยแพร่ชื่อ)
4. ดาวน์โหลด schedule.json ตรวจเนื้อหาก่อนเผยแพร่ แล้วนำไปแทน docs/schedule.json ใน Repository และ Commit changes
5. เมื่อ Pages เผยแพร่เสร็จ ให้ครูโหลดหน้าใหม่

เครื่องมือไม่ส่งไฟล์สำรองออกไปทางเครือข่าย คัดเฉพาะชื่อหลักสูตร วัน เวลา วิชา สถานที่ การแต่งกาย และชื่อผู้สอนหากเลือก ไม่คัดลอกข้อมูลผู้ใช้ รหัสผ่าน รายชื่อครูทั้งหมด หมายเหตุภายใน หรือผู้ลงนาม
ไฟล์ schedule.json เริ่มต้นว่างเพื่อให้ผู้ดูแลเลือกข้อมูลที่จะเผยแพร่ก่อน ทุกข้อมูลใน docs เป็นข้อมูลสาธารณะ รวมถึงประวัติไฟล์ที่ Commit แล้ว
สิทธิ์แก้ไขควบคุมด้วยบัญชี GitHub ผู้ที่เปิดหน้าเว็บไม่สามารถบันทึกกลับ Repository ได้ ไม่ใส่ Token ลง JavaScript
โปรแกรมจัดตารางเดิมยังเป็นเครื่องมือแก้ไข ชุดนี้เป็นหน้าดู/พิมพ์และเครื่องมือแปลงข้อมูล ไม่ใช่ระบบจัดตารางร่วมกัน

## ทดสอบในเครื่อง
รัน python -m http.server 8080 --directory docs แล้วเปิด http://localhost:8080 (การเปิด index.html โดยตรงอาจโหลด JSON ไม่ได้)

คู่มือ GitHub: https://docs.github.com/en/pages/quickstart
